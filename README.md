# 클래스로그 (Class Log)

클래스로그는 소규모 학원, 개인 레슨, 동아리형 수업의 운영자와 학생을 위한 모바일 우선 반응형 웹앱입니다. 운영자는 학생별 월간 활동 구성, 일정, 출석, 보강, 수업 피드백을 한곳에서 관리하고, 학생은 자신의 일정과 피드백을 확인하고 답변할 수 있습니다.

현재 저장소는 공모전 시연용 MVP의 개발 기반만 제공합니다. 실제 수강생 데이터는 사용하지 않으며, 로그인과 수업 관리 기능은 아직 연결되어 있지 않습니다.

## 기술 구성

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- ESLint
- Supabase JavaScript Client
- Supabase SSR

## 시작하기 전에

컴퓨터에 Node.js와 npm이 설치되어 있어야 합니다. 터미널에서 다음 명령으로 확인할 수 있습니다.

```bash
node --version
npm --version
```

## 설치 방법

저장소를 내려받은 뒤 프로젝트 폴더에서 의존성을 설치합니다.

```bash
npm install
```

## 환경변수 설정

1. 프로젝트 루트의 `.env.example` 파일을 복사합니다.
2. 복사한 파일 이름을 `.env.local`로 변경합니다.
3. 실제 Supabase 프로젝트를 연결할 때만 아래 두 값을 `.env.local`에 입력합니다.

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

`.env.local`은 Git에 포함되지 않습니다. 실제 키, 비밀번호, 개인정보를 코드나 README에 기록하거나 커밋하지 마세요. 현재 화면 확인에는 Supabase 값이 필요하지 않습니다.

## 개발 서버 실행

```bash
npm run dev
```

터미널에 표시된 주소(기본값 `http://localhost:3000`)를 브라우저에서 열면 됩니다.

확인할 화면은 다음과 같습니다.

- 홈: `/`
- 운영자 로그인 UI: `/login/operator`
- 학생 로그인 UI: `/login/student`

## 코드 검사와 프로덕션 빌드

```bash
npm run lint
npm run build
```

두 명령이 오류 없이 끝나면 기본 코드 품질 검사와 프로덕션 빌드가 정상적으로 완료된 것입니다.

## 현재 구현 범위

- 모바일 우선 홈 화면
- 운영자 로그인 화면 UI
- 학생 로그인 화면 UI
- Supabase 브라우저 클라이언트 생성 함수
- 환경변수 예시와 보안 기본 설정
- 운영자 이메일·비밀번호 로그인
- 학생 닉네임·비밀번호 로그인
- 쿠키 기반 세션 갱신, 보호 경로와 로그아웃

## 인증 확인

운영자는 Supabase Auth에 등록되고 이메일 확인이 완료된 계정으로 로그인합니다. 학생은 화면에 닉네임을 입력하며, 앱이 정규화된 닉네임을 내부 인증용 가상 이메일로 변환합니다. 학생 직접 회원가입과 계정 생성 기능은 제공하지 않습니다.

로그인 후 이동 경로는 다음과 같습니다.

- 운영자: `/operator`
- 학생: `/student`

현재 두 경로는 로그인 여부만 확인하는 임시 화면입니다. `operator`와 `student` 역할 타입은 준비되어 있지만 역할별 서버 권한 검증은 아직 구현되지 않았습니다.

## 아직 구현하지 않은 기능

- 역할별 사용자 권한
- 학생 관리
- 일정, 출석, 보강, 피드백 관리
- 데이터베이스 테이블과 SQL
- 파일 업로드
- 실제 데이터 또는 더미 학생 데이터
- 배포 설정
